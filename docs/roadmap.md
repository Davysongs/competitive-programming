# Roadmap

The repository grows by verified depth, not translation volume.

## Near Term

- Add diverse problems in arrays, searching, graphs, trees, and data structures.
- Migrate existing C++ references when source bundles contain them.
- Add the first idiomatic Go implementation after local or CI compilation is available.
- Select a Rust problem where ownership or memory layout is materially relevant.

## Tooling

- Add focused tests for additional generator and comparator types as they appear.
- Consider parallel test execution only when repository size makes sequential CI slow.
- Add metadata schema versioning when a real incompatible change requires it.

## Algorithm Notes

Add reusable implementations only when they teach a general technique rather than
copying a problem solution into a second location.
