# Algorithm Reference

This area contains reusable study implementations, not copies of submitted
solutions. Each module should explain an invariant or data structure that applies
across problems and should have focused unit tests.

## Current Modules

- [Suffix automaton](strings/suffix_automaton.py): incremental construction,
  substring membership, and distinct-substring counting.

Problem-specific choices, rank arithmetic, JSON adapters, and contest constraints
remain with their problem bundles.
